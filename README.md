## 🚀 Projects

### 📡 [Packet Sniffer](https://github.com/kaganksgl/packet_sniffer) &nbsp;`C` `Python` `Tkinter`
A Linux packet capture tool built on `AF_PACKET` raw sockets, with no libpcap dependency. It decodes Ethernet, IPv4, TCP and UDP headers, hex-dumps payloads, and filters by IP, port, protocol and interface. A small Tkinter desktop app adds a live view, a packet counter and log export. It can run without root through `CAP_NET_RAW`, and writes logs with `0600` permissions.

### 🖥️ [InfraWatch](https://github.com/kaganksgl/personal-infrastructure-monitor) &nbsp;`Python` `FastAPI` `React` `PostgreSQL` `Docker`
A self-hosted infrastructure monitoring system for Linux machines. An agent collects CPU, memory, disk, network, sensor and process data every 5 seconds and buffers it locally so outages don't lose samples. A FastAPI server stores it with three-tier retention and runs rule-based alerts, and a React dashboard shows fleet and per-machine history live over WebSockets. Includes admin and viewer roles, per-agent API keys and an audit log.

### 🎵 [Riffly](https://github.com/kaganksgl/riffly) &nbsp;`TypeScript`
"A diary for songs": a social platform for rating, reviewing and collecting individual songs rather than albums. It has logs, short takes called riffs, long-form reviews, crates, setlists and a discovery feed. The repo holds a full product blueprint plus a working backend and web client, covered by an automated test suite.

### 🚭 [Quittify](https://github.com/kaganksgl/quittify_app) &nbsp;`HTML` `CSS` `JavaScript` `PWA`
A habit-quitting tracker with live clean-time counters, money saved, milestones from 1 hour to 1 year, and relapse tracking that keeps history. It is a single-file, zero-dependency PWA with no backend: all data stays in the browser. English and Turkish, light and dark themes, and JSON backup and restore.

### 📝 [Taskion](https://github.com/kaganksgl/Taskion) &nbsp;`Dart`
A mobile app for daily planning.

### 🦀 [log_analyzer](https://github.com/kaganksgl/log_analyzer) &nbsp;`Rust`
A log analyzer written in Rust, built with Cargo.
